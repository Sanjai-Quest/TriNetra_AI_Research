# ⚠️ QUARANTINE NOTICE

**Status:** SYNTHETIC — NOT REAL-WORLD DATA  
**Audit reference:** [`audit/label_and_leakage_findings.md`](label_and_leakage_findings.md)  
**Date quarantined:** 2026-10-23

## What this directory contains

- `customer_complaints_dataset.csv` (271 rows): Template-generated consumer dispute scenarios produced by `expand_master_dataset.py`. All URLs are fabricated by string interpolation.
- `trinetra_real_complaints_expanded.csv` (1,050 rows): Extension of the above via `build_trinetra_1000_corpus.py`. All URLs, social metrics, and dates are synthetic.
- Associated quality reports and analysis documents.

## Why it is quarantined

These records were generated by Python template scripts (see Findings F-01 through F-03 in the audit). They were previously misrepresented as authentic consumer complaints collected from social media platforms. They must not be cited as real consumer complaints, real physical measurements, or validated research results.

## Permitted use

- As explicitly labeled synthetic test fixtures
- As regression inputs when the test harness tags them `[SYNTHETIC]`
- For code debugging only

## Prohibited use

- As evidence of real-world validity
- As ground truth for research evaluation
- As training data without disclosure
- As source material for academic claims of authenticity
